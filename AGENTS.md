# AGENTS.md — non-negotiable repo rules

You are editing hand-crafted HTML notes for JEE Advanced + Olympiad math.
`PnC/` and `Complex Numbers/` are golden references: **read before writing**.
When this file and a golden file seem to disagree, follow this file for NEW
content and never rewrite the goldens.

## Structure (MUST)

- Module = one top-level folder containing `index.html`, chapters
  `01-…`…`06-…`, `olympiad-paper.html`, `olympiad-paper-solutions.html`,
  a generated `*-mindmap.html`, `assets/notes.css`.
- **ONE chapter = ONE single large HTML file.** Never split a chapter into
  several HTML files. Never merge two chapters into one.
- New module folder names: kebab-case slugs (`Quadratic-Equations/`).
  `Complex Numbers/` keeps its space. Do not rename existing folders/files.
- `{{module}}-mindmap.html` is GENERATED by `tools/build-mindmap.py` —
  NEVER hand-write or hand-edit a mind map.
- Copy `assets/notes.css` into a new module folder; no cross-folder links.

## Head (exact, every page)

```html
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>…</title>
<link rel="stylesheet" href="assets/notes.css">
<script>
window.MathJax = {
  tex: { inlineMath: [['\\(', '\\)']], displayMath: [['$$', '$$'], ['\\[', '\\]']] },
  svg: { fontCache: 'global' }
};
</script>
<script async src="https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-mml-chtml.js"></script>
```

Only `<title>` varies. Do not swap in `tex-chtml-full`, KaTeX, or local copies.

## Body skeleton (MUST)

`nav.topnav` (brand · Home · chapter links · Paper · Solutions; current page =
highlighted `<span>`, not a link) → `div.page` → `header.ch-head`
(`.ch-kicker`, `<h1>`, `.ch-sub`) → content in `div.card` blocks →
`div.foot` with back-links. Copy `templates/chapter.html` instead of
inventing markup.

## Components (MUST, exact classes)

- Callout: `div.box.box-first|box-idea|box-note|box-warn|box-check|box-bridge|box-identity|box-olymp`
  with a first child `div.box-title`.
- Question: `div.q` → `div.q-head` → `span.q-id` (`P#`/`Q#`/`S#`) +
  `span.badge` (`b-main` JEE Main · `b-adv` JEE Advanced · `b-olymp` Olympiad ·
  `b-pract` · `b-concept` · `b-solved`; `b-oly`/`b-hard`/`b-mod` exist only in
  older files — do not introduce them in new content).
- Practice: problem `p`, then `details.ans` → `summary` → `div.ans-body`;
  solution = **method name first**, derivation, then a check.
- Worked example: `div.q.solved` → `div.solution` → `div.sol-title`.
- Paper question: like practice but the answer is inline and short:
  `p.answer-pill` ("Answer: …").

## Numbering (MUST)

- Practice: `P1…Pn` continuous **per module** (unique across all chapters),
  interleaved between theory sections — not appended at chapter ends.
- Worked examples: `S1…Sn`, continuous per module.
- Paper: `Q1…Qn`, ≥30 (aim 38–40), lettered sections A–H as separate
  `div.card`s, difficulty ramping Main → Advanced → Olympiad; solutions file
  repeats Q-ids verbatim and answers every one.

## Correctness (MUST)

- Every paper answer is verified **numerically in pure Python (stdlib only —
  no numpy, no sympy)** BEFORE the solutions file is written. Unverified answer
  ⇒ reject your own work.
- Math is real TeX in MathJax delimiters `\(…\)`, `\[…\]`, `$$…$$`. NEVER
  fake math with Unicode glyphs (`x² √ ≤ ≈ ℝ`).
- HTML must be well-formed: every tag balanced and properly nested.

## Verify (MUST, before finishing)

```bash
python3 tools/verify-math.py                    # every *.html — all lines PASS
python3 tools/verify-mindmap.py all             # mind maps complete vs sources
python3 tools/build-mindmap.py all && git diff --quiet   # mind maps regenerate unchanged
```

Non-PASS output ⇒ fix the file; do not commit, do not loosen the verifier to
make content pass.

## Forbidden (NEVER)

- Never modify existing note content in `PnC/` / `Complex Numbers/` —
  tooling moves only, and only if mind-map regeneration stays byte-identical.
- Never add dependencies, build systems, frameworks, generated caches, or
  image files (maintainer opted out).
- Never rename module folders or the files listed in "Structure" above.
- Never push to `main` or force-push; work on a branch and open a PR.
- Never commit answers that were not numerically verified.

## New module procedure

Follow `templates/CHECKLIST.md` (10 steps): folder + `assets/notes.css` →
`index.html` from `templates/module-index.html` → chapters `01-…`…`06-…` from
`templates/chapter.html` → continuous P-numbering → paper (≥30 Q, A–H, answer
pills; **pure-Python verification first**) → `templates/olympiad-paper-solutions.html`
→ `python3 tools/build-mindmap.py <module>` → run both verifiers → update the
README modules table → PR.
