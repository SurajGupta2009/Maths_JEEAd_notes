# AGENTS.md — non-negotiable repo rules

You are editing hand-crafted HTML notes for JEE Advanced + Olympiad math.
The four published module maps are the final course artifacts; use the source
patterns in `templates/` and the existing maps as references when authoring a
future source-backed module. When this file and an existing artifact disagree,
follow this file for NEW content.

## Structure (MUST)

- A **published** module is one top-level folder containing exactly one
  standalone `*-mindmap.html` and its local `assets/notes.css`. The mindmap
  embeds the former index, six chapters, Olympiad paper and full solutions;
  it is the only course HTML file users need.
- The source layout used before publication was `index.html`, chapters
  `01-…`…`06-…`, `olympiad-paper.html`, and
  `olympiad-paper-solutions.html`. Those source pages are intentionally removed
  from the four published modules after the map passes the completeness audit.
- New module folder names: kebab-case slugs (`Quadratic-Equations/`).
  `Complex Numbers/` keeps its space. Do not rename existing folders/files.
- `{{module}}-mindmap.html` is GENERATED by `tools/build-mindmap.py` —
  NEVER hand-write or hand-edit a mind map. A source-less map is safely left
  unchanged by the builder.
- Copy `assets/notes.css` into a new module folder; no cross-folder links.

## Head (exact, every source page)

The published mindmaps embed the stylesheet and retain the same MathJax
configuration; their generated head is intentionally self-contained.

```html
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>…</title>
<link rel="stylesheet" href="assets/notes.css">
<script>
window.MathJax = {
  tex: { inlineMath: [['\\(', '\\)']], displayMath: [['$$', '$$'], ['\\[', '\\]']] },
  svg: { fontCache: 'global' }
};
</script>
<script async src="https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-mml-chtml.js"></script>
```

Only `<title>` varies. Do not swap in `tex-chtml-full`, KaTeX, or local copies.

## Body skeleton (MUST)

Source pages use `nav.topnav` (brand · Home · chapter links · Paper ·
Solutions; current page = highlighted `<span>`, not a link) → `div.page` →
`header.ch-head` (`.ch-kicker`, `<h1>`, `.ch-sub`) → content in `div.card`
blocks → `div.foot` with back-links. The published map normalizes those pages
into `<details class="mm-ch">` nodes, preserving each hero and converting
cross-page links to stable in-map anchors. Copy the source templates instead
of inventing markup when creating a future module.

## Components (MUST, exact classes)

- Callout: `div.box.box-first|box-idea|box-note|box-warn|box-check|box-bridge|box-identity|box-olymp`
  with a first child `div.box-title`.
- Question: `div.q` → `div.q-head` → `span.q-id` (`P#`/`Q#`/`S#`) +
  `span.badge` (`b-main` JEE Main · `b-adv` JEE Advanced · `b-olymp` Olympiad ·
  `b-pract` · `b-concept` · `b-solved`; `b-oly`/`b-hard`/`b-mod` exist only in
  older files — do not introduce them in new content).
- Practice: problem `p`, then `details.ans` → `summary` → `div.ans-body`;
  solution = **method name first**, derivation, then a check.
- Worked example: `div.q.solved` → `div.solution` → `div.sol-title`.
- Paper question: like practice but the answer is inline and short:
  `p.answer-pill` ("Answer: …").

## Numbering (MUST)

- Practice: `P1…Pn` continuous **per module** (unique across all chapters),
  interleaved between theory sections — not appended at chapter ends.
- Worked examples: `S1…Sn`, continuous per module.
- Paper: `Q1…Qn`, ≥30 (aim 38–40), lettered sections A–H as separate
  `div.card`s, difficulty ramping Main → Advanced → Olympiad; solutions file
  repeats Q-ids verbatim and answers every one.

## Correctness (MUST)

- Every paper answer is verified **numerically in pure Python (stdlib only —
  no numpy, no sympy)** BEFORE the solutions file is written. Unverified answer
  ⇒ reject your own work.
- Math is real TeX in MathJax delimiters `\(…\)`, `\[…\]`, `$$…$$`. NEVER
  fake prose math with Unicode glyphs (`x² √ ≤ ≈ ℝ`); SVG diagram labels may
  use readable glyphs when they are literal drawing text rather than MathJax.
- HTML must be well-formed: every tag balanced and properly nested.
- Before source removal, manually review each map for complete expandable
  theory, every question/answer, text and symbol rendering, and every figure;
  the verifiers must also report matching figures, tables and formulas.

## Verify (MUST, before finishing)

```bash
python3 tools/verify-math.py                    # every remaining *.html — all PASS
python3 tools/verify-mindmap.py all             # source-backed or standalone checks
python3 tools/build-mindmap.py all              # source-less maps are safe no-ops
```

Before deleting source pages, run the source-backed completeness check and
record the counts for questions, answers, figures, tables and formulas. After
deleting them, rerun both verifiers; `verify-mindmap.py` must switch to its
standalone integrity checks and no retained map may contain a local source-page
link. Compare generated map files with `git diff --exit-code -- '*mindmap.html'`
when checking reproducibility. Non-PASS output ⇒ fix the file; do not commit,
do not loosen the verifier to make content pass.

## Forbidden (NEVER)

- Never hand-edit generated mindmaps or add dependencies, build systems,
  frameworks, generated caches, or image files (maintainer opted out).
- Do not change curated source content casually; requested mathematical/text
  corrections must be checked by the math gate and then reflected by a fresh
  map generation before source removal.
- Never rename module folders or the retained map files listed in "Structure".
- Never push to `main` or force-push; work on a branch and open a PR.
- Never commit answers that were not numerically verified.

## New module procedure

Follow `templates/CHECKLIST.md` (10 steps) while authoring a new module:
folder + `assets/notes.css` → `index.html` from `templates/module-index.html`
→ chapters `01-…`…`06-…` from `templates/chapter.html` → continuous P-numbering
→ paper (≥30 Q, A–H, answer pills; **pure-Python verification first**) →
`templates/olympiad-paper-solutions.html` →
`python3 tools/build-mindmap.py <module>` → source-backed completeness and visual
review → remove source HTML only after the map is standalone → rerun both
verifiers → update the README modules table → PR.
