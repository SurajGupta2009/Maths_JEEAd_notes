## Formatting Conventions

- **Math**: inline `$...$`, display `$$...$$` (MathJax compatible)
- **Callouts**: blockquote with bold title — First Principles, Key Idea, Common Trap, Olympiad Extension
- **Diagrams**: SVG assets in `assets/` + Mermaid flowcharts where applicable
- **Questions**: `#### P1 ...` with collapsible `<details>` for answers
- **Tables**: GitHub Flavored Markdown tables
- **Theory Order**: Each module follows 6 chapters building from foundations to Olympiad frontier, with worked examples (S), practice (P), and capstone paper (Q)

## Coverage — JEE Advanced & Olympiad

Each module includes:
- **JEE Main**: direct formula application, product/sum rule, basic permutations
- **JEE Advanced**: restricted selections, gap method, derangements, stars & bars with bounds, binomial identities, generating functions
- **Olympiad**: bijections, involutions, double counting, inclusion–exclusion, rook polynomials, Catalan & reflection principle, Burnside–Pólya, partitions, Stirling/Bell numbers, Sperner, Erdős–Szekeres, probabilistic method, cycle lemma
